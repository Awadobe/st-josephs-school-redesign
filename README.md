# St. Joseph's School — Modern Redesign

Multi-page static redesign of https://stjosephshischool.com/
Poppins (body) + Sora (headings). No build step.

Pages: Home, About, School, Vocational, Audiology, Students, Media, Support, Contact.

## Deploy to Netlify (GitHub)

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/Awadobe/st-josephs-school-redesign)

Or manually:
1. Go to https://app.netlify.com/start
2. Import from GitHub → `Awadobe/st-josephs-school-redesign`
3. Build command: empty / Publish directory: `.`
4. Deploy. Done — every `git push` redeploys.
